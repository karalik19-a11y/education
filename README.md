# 📚 Книжный страж

Настольное приложение (Windows / Linux / macOS), которое **блокирует Wi-Fi** и
открывает доступ к сети только после того, как владелец компьютера
**прочитает вслух 50 страниц книги** и пройдёт лёгкий тест по прочитанному.
Слова сверяются с текстом книги **в реальном времени** (офлайн-распознавание
речи Vosk) — «просто посидеть у микрофона» не сработает.

## Возможности (v2.0)

- 🎤 **«Живое» распознавание без задержек**
  - слова засчитываются **по ходу речи** (по промежуточным результатам),
    а не после паузы/тишины — прогресс идёт сразу;
  - модель загрузки **один раз в фоне** при старте (стартовое окно не
    ждёт загрузки модели);
  - короткие аудиоблоки 0.25 с → строка «🎤 ВЫ ГОВОРИТЕ» обновляется
    ~4 раза в секунду;
  - **большая живая строка расшифровки** — видно в реальном времени,
    что именно вы говорите; ниже — подтверждённые слова
    (зелёные — из книги, красные — мимо);
  - индикатор уровня микрофона (видно, что микрофон работает);
  - защита от «затора»: если компьютер не успевает — лишнее аудио
    отбрасывается, а не копится в очереди (нет растущей задержки).
- 🎯 **Две модели точности на выбор** (в «⚙ Настройках» и в установщике):
  - *быстрая* (~33 МБ) — для слабых компьютеров;
  - *максимальная точность* (~1.4 ГБ) — минимум ошибок в словах.
- 🛡 **Защита от удаления без пароля**: фоновый «страж» держит скрытую
  резервную копию и мгновенно восстанавливает программу, если её
  удалили/перенесли. Удаление возможно **только по паролю** —
  `uninstall.bat` / `uninstall.sh` / кнопка «Удалить» в программе.
- 🚀 **Гарантированный запуск по ярлыку**:
  - самовосстанавливающийся запуск (до 3 попыток + лог `data\startup.log`);
  - защита от «зависшего» экземпляра (старый ключ автоматически
    перехватывается — закрытая/упавшая программа не мешает новому запуску,
    в том числе после перезагрузки);
  - ошибки старта видны пользователю (окно с причиной + лог), а не молчат;
  - на Windows ставятся **оба** механизма автозапуска сразу: ключ реестра
    `Run` + задача Планировщика `ONLOGON` (с админ-правами) — приложение
    поднимается после любой перезагрузки;
  - ярлыки «Книжный страж» и «Книжный страж (админ)» (второй — с
    RunAs, блокирует Wi-Fi без UAC-запросов).
- 🎨 **Премиальный тёмный интерфейс**: кольцо прогресса, карточки,
  тосты вместо навязчивых окон, большая живая строка речи, кнопки
  A–D в тесте, экран настроек (модель, микрофон, проверка микрофона).
- ⚡ **Экстренные действия**:
  - «⚡ Экстренный доступ» — пароль `67676767` сразу включает Wi-Fi;
  - «🔒/⚡ Заблокировать Wi-Fi» и «⚡ Экстренное отключение Wi-Fi» —
    мгновенная блокировка;
  - «⏹ Стоп» на экране чтения — мгновенная остановка распознавания.
- 📏 Норма: **50 страниц** (1 страница = 1000 знаков), прогресс
  сохраняется между сессиями.
- ✅ Лёгкий тест из 5 вопросов (для зачёта — 3 верных).
- 📖 Библиотека из 10 книг школьной программы (7 класс) — SQLite
  `data/library.db`.
- 🧪 Режимы `demo` и `simulate` для проверки без микрофона и администратора.

## Установка и запуск

Смотрите **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)** — там всё по шагам.

Кратко:
- Windows: `install.bat` (лучше от администратора), запуск — ярлык
  «Книжный страж (админ)» или `run.bat`.
- Linux/macOS: `bash install.sh`, запуск — `bash run.sh`.
- Удаление: `uninstall.bat` / `bash uninstall.sh` — **только по паролю
  `67676767`** (или кнопка «Удалить» в программе).

## Структура

```
bookguard/            программа (GUI + CLI)
  app.py              интерфейс (тёмная «премиум» тема, живая строка речи)
  stt.py              Vosk-распознавание: живые partial-результаты,
                      фоновая загрузка модели, скачивание моделей
  matcher.py          сверка речи с книгой (пропуски, окончания, fuzzy)
  protector.py        «страж»: резервная копия, само-восстановление,
                      удаление по паролю
  single_instance.py  один экземпляр + перехват «мёртвого» ключа
  autostart.py        автозапуск (реестр + Планировщик / XDG / LaunchAgents)
  wifi.py             блокировка Wi-Fi (netsh / nmcli+rfkill / networksetup)
  quiz.py, db.py      тест и база данных
data/
  library.db          база: 10 книг + страницы + вопросы тестов
models/               модели распознавания (скачиваются установщиком)
install.sh / install.bat      установщики (модель на выбор, ярлыки, страж)
run.sh   / run.bat            самовосстанавливающийся запуск
guard.bat                   скрытый фоновый страж (Windows)
uninstall.sh / uninstall.bat удаление только по паролю
```

## Технические детали

- Распознавание: [Vosk](https://alphacephei.com/vosk/) (офлайн — работает
  и при заблокированном интернете). Поток: микрофон → блоки по 0.25 с →
  `PartialResult` → `PartialConsumer` (стабилизирует слова, держит
  «неустойчивое» последнее) → матчер → подсветка/прогресс в GUI.
- Матчер терпит пропуски и искажения распознавания (совпадение по основе +
  расстояние Левенштейна 1–2 для длинных слов), но чужой текст не
  засчитывает и показывает предупреждение.
- «Страж» (защита от удаления): скрытое зеркало в папке пользователя
  (Windows: `%LOCALAPPDATA%\BookGuard`, Linux: `~/.local/share/bookguard`),
  фоновый процесс без окна, отдельный пункт автозапуска. При удалении
  папки программы — восстанавливает её за секунды. Сам «страж» выключается
  только по паролю (в этом случае резервное зеркало тоже удаляется).
- Тексты — общественное достояние (РусЛит), при желании дополняются через
  `tools/fetch_sources.sh` + `tools/build_library.py`.
- Сквозная проверка: `python -m bookguard selftest` (матчер, живое
  распознавание, конвейер, страж, пароль, одиночный экземпляр, Wi-Fi,
  тест) и `python -m bookguard simulate` (полный игровой цикл без GUI).
