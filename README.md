# Книжный страж

Настольная утилита (Windows / Linux / macOS), которая **блокирует Wi-Fi** и открывает
доступ к сети только после того, как владелец компьютера **прочитает вслух 50 страниц
книги** и пройдёт лёгкий тест по прочитанному. Слова сверяются с текстом книги в
реальном времени (офлайн-распознавание речи Vosk) — «просто посидеть у микрофона»
не сработает.

## Возможности

- 🔒 Блокировка/включение Wi-Fi (Windows: netsh, Linux: nmcli/rfkill, macOS: networksetup).
- 📖 Библиотека из 10 книг школьной программы (7 класс) — SQLite `data/library.db`.
- 🎤 Проверка чтения именно назначенной книги: распознанная речь сверяется со словами
  текста (матчер терпит пропуски/ошибки распознавания, но не чужой текст).
- 📏 Норма: **50 страниц** (1 страница = 1000 знаков), прогресс сохраняется между сессиями.
- ✅ Лёгкий тест из 5 вопросов по прочитанным страницам (для зачёта — 3 верных).
- 🔑 Экстренный пароль `67676767` — немедленно включить Wi-Fi.
- 🚀 Автозапуск вместе с системой (Windows: Планировщик задач + реестр +
  папка «Автозагрузка» сразу; Linux: XDG autostart; macOS: LaunchAgent) —
  Wi-Fi блокируется сразу при включении компьютера. Проверка:
  `python -m bookguard autostart doctor`, переключатель — на главном экране.
- 📝 Читаемый текст: подбор установленных шрифтов, чёткий рендер на HiDPI
  (Windows), размер букв регулируется кнопками A−/A+ (или Ctrl + колесо мыши),
  текст можно выделять и копировать, длинные строки переносятся под ширину окна.
- 🗒 Журнал `data/logs/bookguard.log`: все ошибки (включая сбои при
  автозапуске, когда окна нет) записываются в файл — причину всегда можно найти.
- 🧪 Режимы `demo` и `simulate` для проверки без микрофона и без администратора.
- 🛟 Защита от «запертого» состояния: окно открывается **до** блокировки Wi-Fi,
  а если приложение не удалось запустить (нет Tkinter/дисплея, сбой), сеть
  **автоматически включается обратно** — без интернета компьютер не остаётся
  (сообщение «Wi-Fi ВКЛЮЧЁН автоматически» — это работа страховки, а не сети).
- 🧯 `python -m bookguard selftest` проверяет и сборку интерфейса: GUI-виджеты
  не имеют права перекрывать служебные атрибуты Tkinter (`_w`, `_name`, `tk`) —
  иначе окно не открывается с `TclError: invalid command name "<число>"`.

## Установка и запуск

Смотрите **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)** — там всё по шагам.

Кратко:
- Windows: `install.bat`, запуск — ярлык «Книжный страж (админ)» или `run.bat`.
- Linux/macOS: `bash install.sh`, запуск — `bash run.sh` (для блокировки Wi-Fi через `sudo`).

## Структура

```
bookguard/          программа (GUI + CLI)
  app.py            интерфейс (Tkinter)
  session.py        книга, прогресс чтения, Wi-Fi (без Tkinter — тестируется)
  logger.py         журнал data/logs/bookguard.log (файл + консоль)
  matcher.py        сверка речи с текстом книги
  stt.py            распознавание речи (Vosk, офлайн)
  wifi.py           блокировка Wi-Fi
  quiz.py, db.py    тест и база данных
data/
  library.db        база: 10 книг + страницы + вопросы тестов
  books/            тексты томов (для чтения с экрана)
  quiz.json         вопросы тестов (исходник)
tools/
  build_library.py  сборка базы из текстов
  fetch_sources.sh  откуда взяты тексты (общественное достояние)
models/             модель распознавания (скачивается установщиком)
install.sh / install.bat / run.sh / run.bat
```

## Технические детали

- Распознавание: [Vosk](https://alphacephei.com/vosk/) `vosk-model-small-ru` (офлайн —
  работает и при заблокированном интернете).
- Тексты — общественное достояние (РусЛит, библиотека library_tg), при желании
  дополняются через `tools/fetch_sources.sh` + `tools/build_library.py`.
- Сквозная проверка логики: `python -m bookguard selftest` и `python -m bookguard simulate`.
