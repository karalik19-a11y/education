# 📖 «Книжный страж» — простая инструкция

Утилита блокирует Wi-Fi на компьютере и открывает его **только после того,
как вы прочитаете вслух 50 страниц книги** (микрофон проверяет, что читаете
именно ту книгу, которую назначила программа) и пройдёте лёгкий тест.

---

## 1. Установка (1 раз)

**Windows:**
1. Установите Python с сайта [python.org](https://python.org/) (галочка «Add Python to PATH»).
2. Щёлкните `install.bat` **правой кнопкой → «Запуск от имени администратора»**
   — всё установится само, на рабочем столе появится ярлык, а программа
   **добавится в автозагрузку**.

Если при запуске появляются обрывки команд (`'sys' is not recognized`,
`'ul' is not recognized`), скачайте обновлённую версию проекта и **распакуйте
весь архив** перед запуском `install.bat`. Файлы `install.bat` и `run.bat`
содержат только ASCII и должны сохраняться без BOM с окончаниями строк
Windows (CRLF). Не переводите сообщения внутри `.bat` на русский.
В исправленном установщике первая строка — `Bookguard installer v2 - Windows ASCII`.
Если установка остановилась с ошибкой, окно останется открытым: скопируйте
сообщение выше строки `ERROR: Installation failed`.

**Linux / macOS:**
```bash
bash install.sh
```
Программа сразу добавляется в автозагрузку.

---

## 2. Как пользоваться (каждый день)

1. **Просто включите компьютер и войдите в учётную запись** — «Книжный страж»
   запустится сам и заблокирует Wi-Fi. (Ручной запуск: ярлык **«Книжный страж
   (админ)»** с рабочего стола, или `bash run.sh` на Linux — лучше через `sudo`.)
2. Программа сама назначит книгу из школьной программы (7 класс) — 10 книг в базе.
3. Нажмите **«▶ Начать чтение вслух»** и читайте текст на экране в микрофон.
   - слова, которые вы прочли правильно, **подсвечиваются зелёным сразу**,
     в реальном времени — останавливаться и жать паузу не нужно;
   - шкала громкости рядом с надписью LIVE показывает, что микрофон вас слышит,
     а строка «🎤» — что именно сейчас распознано;
   - счётчик показывает, сколько страниц уже прочитано;
   - читать нужно **50 страниц** (это около часа);
   - сверху показана текущая страница — листать можно стрелками ◀ ▶
     (или клавишами ← → на клавиатуре, пробел — пауза/продолжить);
   - если слов не слышно — нажмите на название микрофона под текстом,
     чтобы выбрать другой микрофон.
4. Когда написано «50 страниц прочитаны» — нажмите **«📝 Пройти тест»**.
   Это **5 лёгких вопросов** по прочитанному. Для зачёта нужно **3 верных ответа**.
5. Тест пройден → **Wi-Fi включён!** 🎉
6. Когда захотите новую книгу — кнопка **«🔄 Новый цикл»** (Wi-Fi снова заблокируется до чтения).

## 3. Срочный доступ в интернет

В любой момент нажмите **«Экстренный доступ»** (вверху справа) и введите пароль:

```
67676767
```

Wi-Fi включится сразу. Снова заблокировать — кнопка «🔒 Заблокировать Wi-Fi»
(или перезапуск программы).

**Если программа вдруг не смогла открыться** (сбой при запуске, нет
графического режима, нет Tkinter) — **Wi-Fi автоматически включается
обратно**, чтобы компьютер не остался без интернета и без окна, где
можно ввести пароль. Причина отображается в консоли/окне; чтобы снова
заблокировать сеть, просто запустите программу повторно.

> Строка «Wi-Fi ВКЛЮЧЁН автоматически (приложение не открылось)» — это не
> поломка сети, а срабатывание страховки. Само приложение нужно починить:
> в сообщении выше указана причина (см. раздел «Частые проблемы»).
Из консоли (без интерфейса):

```bash
python -m bookguard unblock    # включить Wi-Fi
python -m bookguard block      # заблокировать Wi-Fi
python -m bookguard status     # статус
```

---

## 4. Автозапуск с компьютера

После установки программа **сама включается вместе с компьютером** и сразу
блокирует Wi-Fi. Управление:

- галочка **«🚀 Запускать автоматически при включении компьютера»** на главном
  экране программы (вкл/выкл);
- или из консоли: `run.sh autostart on` / `run.sh autostart off` /
  `run.bat autostart status` (Windows: `run.bat autostart on` и т.д.).

## 5. Важные мелочи

- ⚠️ Если программа пишет **«Похоже, вы читаете не ту книгу»** — вы читаете
  другой текст, прогресс не идёт. Читайте текст, показанный на экране.
- 🎤 Микрофон должен быть подключён и разрешён для программы.
- 📚 Книги (7 класс): Пушкин «Дубровский», Лермонтов «Мцыри», Гоголь «Ночь перед
  Рождеством», Тургенев «Записки охотника», Некрасов «Крестьянские дети»,
  Л. Толстой «Кавказский пленник», Лесков «Левша», Чехов «Рассказы»,
  Пришвин «Кладовая солнца», Пушкин «Повести Белкина».
- 🧪 Проверить программу без микрофона: `bash run.sh demo` (или `run.bat demo`) —
  текст «начитается» сам, для демонстрации.
- ⚙️ Заблокировать/включить Wi-Fi вручную из консоли: `run.sh block` / `run.sh unblock`.
- 🔐 Чтобы блокировка работала, запускайте программу **от имени администратора**.

Удачного чтения! 📖

## 6. Частые проблемы

| Сообщение при запуске | Что это значит | Что делать |
| --- | --- | --- |
| `invalid command name "<число>"`, окно не открылось, «Wi-Fi включён автоматически» | Внутренняя ошибка интерфейса (Tkinter) на этапе сборки окна — страховка вернула интернет | Обновите программу и запустите заново: прогресс-бары больше не перекрывают служебные поля Tkinter. Проверить сборку: `run.bat selftest` / `bash run.sh selftest` |
| `Не найдена база данных: data\library.db` | Распакован не весь архив | Распакуйте архив целиком, затем `install.bat` |
| `Не установлены модули vosk/sounddevice` | Не выполнился установщик зависимостей | `install.bat` (Windows) или `bash install.sh` (Linux/macOS) |
| `Не удалось заблокировать Wi-Fi. Нужны права администратора` | Запуск без прав | Windows: ярлык «Книжный страж (админ)»; Linux: `sudo bash run.sh` |
| `'sys' is not recognized` при установке | Файл `install.bat` сохранён с битой кодировкой | Скачайте заново `install.bat`/`run.bat`, распакуйте архив целиком |

Если запуск снова упал — выполните `run.bat` (или `bash run.sh`) **из консоли**,
чтобы видеть полное сообщение об ошибке, и пришлите его: оно начинается со
строки `⚠ «Книжный страж» не удалось запустить:`.
